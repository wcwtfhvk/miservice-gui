MiService Windows 版使用说明
================================

本目录提供两个版本，均无需安装 Python 或任何依赖：

    MiService-GUI.exe   - 图形界面版（推荐）：
                          输入文字让小爱音箱播报 TTS、列出设备并点选播放、
                          暂停/继续/停止、音量、播放网络音频、播放本地音频文件、
                          查看播放状态与最近问答。
    miservice.exe       - 命令行版：适合脚本化调用，用法见文末。

----------------------------------------------------------------
一、图形界面版 MiService-GUI.exe
----------------------------------------------------------------

1. 双击 MiService-GUI.exe 启动。

2. 在顶部输入小米账号和密码，点击【获取设备】。
   - 首次登录如果触发小米二次验证，会弹出验证码输入框，按提示输入即可。
   - 登录状态保存在 %USERPROFILE%\.mi.token，之后无需重复登录。
   - 勾选「记住账号」只保存用户名，不保存密码。

3. 设备列表区：
   - 以表格列出所有小爱设备（名称 / 型号 / deviceID / miotDID）。
   - 用鼠标点选一台或多台设备（按住 Ctrl / Shift 可多选）。
   - 目标范围：
       · 「选中的设备」= 只对勾选的设备执行操作
       · 「全部设备」  = 对所有设备执行操作
       · 未选中任何设备时默认作用于全部设备。

4. 【文字播报 (TTS)】页签：
   - 在文本框输入要让小爱播报的内容，例如「今晚八点开会，请准时参加」。
   - 点击【立即播报】，所选设备（或全部设备）即会朗读。
   - 【清空】按钮清空输入框。

5. 【播放控制】页签：
   - 暂停 / 继续播放 / 停止：控制当前播放。
   - 音量：拖动滑块选择 0-100，点击【设置音量】生效。
   - 播放网络音频：输入 http(s) 音频直链，点击【播放链接】。
   - 【播放状态】查看所选设备当前播放信息（JSON）。
   - 【最近问答】查看小爱最近一次回答的内容。

6. 【本地音频】页签（播放电脑上的音乐文件）：
   - 点击【浏览…】选择本机音频文件（mp3 / wav / m4a / flac 等）。
   - 端口保持 0 即自动分配，一般无需修改。
   - 点击【播放本地音频】，程序会在本机启动一个临时 HTTP 服务，
     生成本机局域网地址（如 http://192.168.x.x:51926/歌曲.mp3），
     再让所选小爱音箱直接拉取并播放该文件；日志区会显示该地址。
   - 前提条件：
       · 小爱音箱与电脑须在同一局域网（同一路由器/Wi-Fi）。
       · 首次使用若被拦截，请在 Windows 防火墙中允许本程序通过「专用网络」。
       · 播放期间请保持程序开启；关闭程序后音频地址立即失效。
       · 若小爱无法播放，可在浏览器打开日志里的地址验证是否可访问。

7. 底部「日志」区显示每步操作的成功/失败结果，便于排查。

8. 【清除登录】按钮：清空本机 token 与界面上的账号信息，下次需重新登录。

----------------------------------------------------------------
二、命令行版 miservice.exe
----------------------------------------------------------------

在 cmd 或 PowerShell 中打开，以便传入参数。

PowerShell：
    $env:MI_USER = "你的小米账号"
    $env:MI_PASS = "你的小米密码"
    $env:MI_DID  = "设备ID或设备名"
    .\miservice.exe list

CMD：
    set MI_USER=你的小米账号
    set MI_PASS=你的小米密码
    set MI_DID=设备ID或设备名
    miservice.exe list

局域网直连（无需云端账号）：
    set MI_LOCAL=设备IP:设备Token
    miservice.exe power

常用命令：
    miservice.exe                       查看全部帮助
    miservice.exe list                  列出设备
    miservice.exe home                  列出家庭
    miservice.exe spec                  查看 MIoT 规格
    miservice.exe 1,1-2,1-3             读取属性
    miservice.exe 2=60                  设置属性
    miservice.exe mina                  列出小爱音箱
    miservice.exe mina 早上好            广播 TTS
    miservice.exe mina pause            暂停播放
    miservice.exe -v5 list              输出 DEBUG 日志

----------------------------------------------------------------

- 账号密码仅用于向小米服务器登录；token 保存在本机用户目录，不会上传第三方。
